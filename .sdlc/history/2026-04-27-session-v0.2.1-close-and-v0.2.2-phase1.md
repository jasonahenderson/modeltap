### Commit 2 — `a595c4d` WU-104: design production wiring (104+105+106)

`designs/2026-04-27-design-production-wiring-104-106.md` (517
lines). Bundles three WUs that share a contract surface per
process §"Design Artifact Placement". Major decisions resolved:

- **async/sync SubmitTurn bridge:** block inside the `tea.Cmd`
  goroutine via a new `ConnectionManager.SubmitTurnSync` helper
  that wraps the existing `TurnSubmittedMsg` event-bridge with a
  per-correlation-id channel
- **ModeReader story for the deleted AppState:** harnesshost owns
  a small `runtimeState` struct that implements `ModeReader`; the
  existing `ToolDispatcher` consumes any `ModeReader` impl
- **CLI command name:** recommended `modeltap shell` (parallels
  `shell-demo`); decision finalized at Phase 2 review
- **Runtime method implementation order:** SubmitTurn → LoadPreview
  → ResolvePermission → InterruptRun → DispatchCommand →
  SummarizePaste. WU-105 starts as soon as SubmitTurn lands

Open questions for Phase 2 review:

- Does the BFF already implement `turn.interrupt` (or equivalent)?
  If not, scope server-side change as WU-104a or accept the
  not-implemented error path.
- Does `ConnectionManager` already expose a sync-promise wrapper
  around `Client.SubmitTurn`?
- Final CLI command name.

### Commit 3 — `3fdc4a6` WU-107: design viewport-state accessor
