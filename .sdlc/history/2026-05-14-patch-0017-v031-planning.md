# 2026-05-14: PATCH-0017 v0.3.1 planning

## Summary

Assigned PATCH-0017 (session-scoped project context) to the v0.3.1 planning
draft.

## Rationale

v0.3.1 owns context planner and project rules. Keeping project context at
connection scope would make later context-plan, prompt-provenance, and
project-rule work build on the wrong boundary. PATCH-0017 is now treated as
prerequisite runtime/project-context plumbing for v0.3.1 rather than as GUI
implementation work.
