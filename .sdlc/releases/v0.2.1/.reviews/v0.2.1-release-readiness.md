## Explicit deferrals carried into v0.2.2

- **WU-100 Stage D-4** — production `Runtime` impl + new production CLI
  entrypoint. `internal/harness/` package files remain on disk
  (compile clean, unit tests pass) but are unreachable from any CLI
  command. v0.2.2 audits and salvages.
- **WU-102 SC3 follow-up** — manual scroll preservation lacks a
  direct automated assertion because viewport state is private inside
  `Model.View`'s local copy. v0.2.2 provides a viewport-state
  accessor.

These are the only known release-scoped gaps. Both have v0.2.2 plan
entries.

## Risks acknowledged at tag time

- **Branch.** Tagged on `spike/scrolling-surface-eval`. The branch
  retarget to a release branch is pending TPM decision; per
  `.agents/process.md` §"Tag update policy", an unpublished tag may
  be moved.
- **Production reach.** v0.2.1 has no production conversation-shell
  entrypoint. `modeltap shell-demo` exercises the full architecture
  against the fake runtime in `internal/harnessdemo`. End users have
  the demo but not real provider access until v0.2.2 ships.
- **Plumbing audit unverified.** The decision to leave
  `internal/harness/` on disk (rather than delete wholesale) is
  predicated on the assumption that some of its plumbing is
  salvageable. WU-103 categorized files; WU-104 will prove or
  disprove the assumption.

## Approval

The release is approved for tagging. v0.2.1 ships the post-extraction
architecture as a structurally-complete deliverable, with production
wiring explicitly scoped to v0.2.2.
