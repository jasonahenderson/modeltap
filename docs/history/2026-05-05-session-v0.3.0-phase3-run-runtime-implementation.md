# 2026-05-05 - v0.3.0 Phase 3 Run Runtime Implementation

## Summary

Started v0.3.0 Phase 3 implementation on `release/v0.3.0`.

Implemented the durable run foundation:

- storage schema version 3 for runs, events, checkpoints, attachments,
  run-turn links, model-call accounting, and tool-result accounting
- storage API and tests for run creation, event sequencing, replay, workflow
  validation, and idempotent model-call accounting

  `run_id` on `turn.submit`

  checkpoints, completion/failure/cancellation updates, and run controls
- production harness routing for `/run`, `/runs`/`/jobs`, `/attach`,
  `/detach`, `/cancel`, `/retry`, `/continue`, and `/fork`
- user and embedding documentation for run commands and run projection
