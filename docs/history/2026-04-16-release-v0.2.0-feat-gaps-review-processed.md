- WU-048 now pins **heartbeat interval 15s**, **heartbeat timeout 30s**, and **session-lock grace period 10s** (total 40s from last pong to lock release). Values are constants in `internal/bff/connection.go` and surfaced in config for future override.

- WU-050 tests now cover: reconnect at 35s keeps the lock, reconnect at 45s is rejected, force-release path.

- WU-061 tests now cover: custom thresholds, explicit `compact_model`, empty `compact_model` fallback via routing.
