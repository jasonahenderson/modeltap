# 2026-04-16 — Design: Bubbletea Scaffold Bundle (WU-068 + WU-069 + WU-070 + WU-071 + WU-072)

## Scope

This is a bundled design covering five related WUs that form the terminal harness UI foundation in `internal/harness/`:

- **WU-068** — Bubbletea app scaffold (`app.go`, `model.go`): main model, three-zone layout, window resize, focus management, key bindings.
- **WU-069** — Status bar component (`statusbar.go`): connection indicator, mode, model, context, cost, timer.
- **WU-070** — Input area component (`input.go`): multi-line textarea, submit key, command detection, @file syntax, history keybindings, paste detection.
- **WU-071** — Conversation viewport component (`viewport.go`): scrollable viewport, auto-scroll, snap-back, message boundaries, metadata, model routing indicator.
- **WU-072** — Streaming markdown rendering (`markdown.go`): Glamour-based, debounced redraw, partial rendering during streaming, final clean render.

**Out of scope:** Protocol client (WU-073), connection manager (WU-074), tools (WU-075–079), features (WU-080–086), history source (WU-092 — keybindings wired here, source plugged in later).

## Bundle Rationale

All five WUs live in `internal/harness/` and compose into a single Bubbletea `tea.Model`. The layout model (068) defines the coordinate space the other four components render into. Status bar (069), input (070), and viewport (071) are children of the layout model. Markdown rendering (072) is a sub-component of the viewport. Designing them together prevents layout assumptions from drifting between components.

#### D2.3. Layout calculation

The three-zone layout is computed on every `tea.WindowSizeMsg`:

```go
func (a *App) calculateLayout() {
    // Status bar: always 1 line at bottom
    statusBarHeight := 1
    
    // Input area: minimum 1 line, grows with content up to 1/3 of terminal
    inputHeight := a.input.Height()
    maxInputHeight := a.height / 3
    if inputHeight > maxInputHeight {
        inputHeight = maxInputHeight
    }
    if inputHeight < 1 {
        inputHeight = 1
    }
    
    // Banner area: 0-2 lines for transient banners (connection, MCP, etc.)
    bannerHeight := a.bannerLines()
    
    // Viewport: remaining space
    viewportHeight := a.height - statusBarHeight - inputHeight - bannerHeight
    if viewportHeight < 1 {
        viewportHeight = 1
    }
    
    a.viewport.SetSize(a.width, viewportHeight)
    a.input.SetWidth(a.width)
    a.statusBar.SetWidth(a.width)
}
```

#### D2.4. Focus management

Input area has focus by default. When the user scrolls up in the viewport (arrow keys / Page Up), focus shifts to `ViewportFocus`. When the user presses a printable character or the viewport reaches the bottom, focus returns to `InputFocus`.

```go
func (a *App) handleFocusSwitch(msg tea.KeyMsg) {
    switch {
    case msg.Type == tea.KeyUp && a.state.Focus == InputFocus:
        // Only switch to viewport if input cursor is at line 0
        if a.input.CursorAtTop() {
            a.state.Focus = ViewportFocus
        }
    case msg.Type == tea.KeyDown && a.state.Focus == ViewportFocus:
        if a.viewport.AtBottom() {
            a.state.Focus = InputFocus
        }
    case msg.Type == tea.KeyRunes && a.state.Focus == ViewportFocus:
        a.state.Focus = InputFocus
    }
}
```

#### D4.1. Submit handling

```go
func (i *InputArea) handleSubmit() tea.Cmd {
    content := strings.TrimSpace(i.textarea.Value())
    if content == "" {
        return nil
    }
    
    msg := SubmitMsg{Content: content}
    
    // Command detection
    if strings.HasPrefix(content, "/") {
        msg.IsCommand = true
        parts := strings.SplitN(content[1:], " ", 2)
        msg.Command = parts[0]
        if len(parts) > 1 {
            msg.CommandArgs = parts[1]
        }
    }
    
    // @file detection
    msg.Attachments = extractFileRefs(content)
    
    i.Reset()
    return func() tea.Msg { return msg }
}

// extractFileRefs finds @path/to/file and @glob patterns in content.
func extractFileRefs(content string) []string
```

#### D4.2. History traversal

```go
func (i *InputArea) handleHistoryUp() {
    if i.historySource == nil || i.historySource.Len() == 0 {
        return
    }
    if i.historyIndex == 0 {
        // Save current draft before starting traversal
        i.savedDraft = i.textarea.Value()
    }
    if i.historyIndex < i.historySource.Len() {
        entry, ok := i.historySource.Entry(i.historyIndex)
        if ok {
            i.textarea.SetValue(entry)
            i.historyIndex++
        }
    }
}

func (i *InputArea) handleHistoryDown() {
    if i.historyIndex <= 0 {
        return
    }
    i.historyIndex--
    if i.historyIndex == 0 {
        i.textarea.SetValue(i.savedDraft)
        return
    }
    entry, ok := i.historySource.Entry(i.historyIndex - 1)
    if ok {
        i.textarea.SetValue(entry)
    }
}
```

#### D4.3. Paste detection

```go
// detectLargePaste checks if pasted content exceeds the threshold.
// Returns a PastDetectedMsg if large paste detected.
type PasteDetectedMsg struct {
    Content   string
    ByteSize  int
    LineCount int
    Preview   string // first 5 lines
}

func (i *InputArea) detectPaste(content string) tea.Cmd {
    if len(content) < i.pasteThreshold {
        return nil
    }
    lines := strings.Split(content, "\n")
    preview := strings.Join(lines[:min(5, len(lines))], "\n")
    return func() tea.Msg {
        return PasteDetectedMsg{
            Content:   content,
            ByteSize:  len(content),
            LineCount: len(lines),
            Preview:   preview,
        }
    }
}
```

#### D5.2. Auto-scroll logic

```go
func (v *ConversationViewport) handleAutoScroll() {
    if v.autoScroll && !v.userScrolled {
        v.viewport.GotoBottom()
    }
}

// Called on manual scroll-up
func (v *ConversationViewport) handleManualScroll(msg tea.KeyMsg) {
    if msg.Type == tea.KeyUp || msg.Type == tea.KeyPgUp {
        v.userScrolled = true
        v.autoScroll = false
    }
    // Snap-back: if viewport reaches bottom, re-enable auto-scroll
    if v.viewport.AtBottom() {
        v.userScrolled = false
        v.autoScroll = true
    }
}
```

#### D5.3. Streaming updates

On `StreamTokenMsg`, the viewport appends the delta to the current streaming message's `Content`, triggers a re-render of that message only (via the markdown renderer), and auto-scrolls if enabled.

On `StreamCompleteMsg`, the viewport marks the message as complete, triggers a final clean markdown render, and updates the per-turn metadata line.

#### D6.1. Streaming tolerance

During streaming, the content may have incomplete markdown blocks (unclosed code fences, partial bold markers, etc.). `RenderStreaming` handles this by:

1. Detecting unclosed fenced code blocks (odd number of ``` markers) → append a closing fence before rendering
2. Detecting unclosed inline code (odd number of ` markers) → append closing backtick
3. Detecting unclosed bold/italic → append closing markers
4. Rendering the "healed" content, then stripping the appended markers from the output

```go
// healPartialMarkdown closes any unclosed markdown blocks so Glamour
// can render without errors. Returns healed content and a list of
// appended suffixes (for stripping from output if needed).
func healPartialMarkdown(content string) (string, []string)
```

#### D6.2. Debounce

```go
func (r *MarkdownRenderer) ShouldRedraw() bool {
    if time.Since(r.lastRender) >= r.debounceInterval {
        r.lastRender = time.Now()
        r.pending = false
        return true
    }
    r.pending = true
    return false
}
```

When `ShouldRedraw()` returns false and `pending` is true, the viewport schedules a `tea.Tick` at `debounceInterval` to ensure the final pending render fires.

#### D6.3. Chunked re-rendering for long responses

For responses exceeding 10KB of rendered content, only re-render the last chunk (from the last rendered position). The viewport tracks `lastRenderedLen` and only passes the new content to `RenderStreaming`, appending the result to the previously rendered output.

```go
// RenderIncremental renders only new content since lastOffset.
// Returns the full rendered string (cached prefix + newly rendered suffix).
```
